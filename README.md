# 성현교회 출석부 · 교인관리 (v0.2)

## 1. 설치 (Windows)
1. GitHub 저장소의 **Releases**에서 `SeonghyeonRoll-Setup-x.y.z.exe`를 받아 설치합니다. (처음 올리는 방법은 4번)
2. 서명되지 않은 프로그램이라 Windows 보호 창이 뜨면 *추가 정보 → 실행*을 누릅니다. 이후 업데이트는 자동입니다.
3. 처음에는 **가상의 예시 데이터**가 들어 있습니다. 둘러본 뒤 화면 위 *예시 지우고 시작*을 누르세요.

데이터는 `문서\성현교회출석부\data.json`에 자동 저장되고, `백업` 폴더에 하루 한 번 사본이 남습니다(최근 60일).
메뉴 *파일 → 데이터 폴더 열기*로 바로 열 수 있습니다.

## 2. 화면 구성
| 메뉴 | 하는 일 |

| 현황 | 지난 주일 출석, 12주 추이, 처리할 일(심사 대상·장기결석·생일) |
| 출석체크 | 수요예배·금요기도회·주일 1/2/3부. 이름 카드를 **탭**하면 출석/취소. 초성 검색, 구역별 보기, *태블릿 모드*(전체 화면), 새가족 즉시 등록 |
| 교인관리 | 직분·생일(양/음)·구역·전도회·봉사활동·세례·등록일·가족·메모. 이름을 누르면 12주 출석, 헌금생활, 심방 기록 |
| 정회원 심사 | 정관 제6조 기준 자동 판정 → 선택 후 *운영위 승인* 기록 → 공동의회 회원명부(제12조)·선거권(제7조) |
| 결석·이명 | 3주/3개월/6개월 결석 단계, 심방 기록, 별명부(제9조)·회원권 정지·복귀, 이명 전출/전입 이력 |
| 헌금생활 | 헌금집계 엑셀(또는 구글시트)에서 **참여 여부와 항목만** 가져옴. 금액은 저장하지 않음 |
| 생일 | 월별 생일자 (음력 표시) |
| 출석부·출력 | 월별 출석부, 교인명부, 공동의회 명부, 결석자 명단 → **Excel / PDF** |
| 설정·데이터 | 판정 기준, 직분·구역·전도회·봉사 목록, 구글시트 연동, 백업/복원 |

### 정회원 판정 (설정에서 숫자 변경 가능)
- 세례(입교)교인이고
- 등록 후 **6개월** 이상, 또는 새가족 교육 이수 시 **3개월** 이상
- 출석 기록이 있는 주일 중 **50%** 이상 출석 (정기 출석 기준, 교회 결정에 맞게 조정)
- 만 18세 이상 → 운영위원회 승인 시 정회원(공동의회 회원)
- 선거권: 등록 후 12개월 정기 출석

## 3. 구글시트 연동
1. 교인관리용 **새 구글시트**를 만들고 *확장 프로그램 → Apps Script*를 엽니다.
2. `gas/Code.gs` 내용을 붙여넣고, 맨 위 `KEY`를 비밀번호로 바꿉니다.
3. *파일 + → HTML*로 `index`라는 파일을 만들고 `gas/index.html` 내용을 붙여넣습니다.
4. *배포 → 새 배포 → 웹 앱* — 실행: **나**, 액세스: **모든 사용자** → 배포 → URL(…/exec) 복사.
5. 데스크탑 앱 *설정·데이터*에 URL과 KEY 입력 → *지금 동기화*.
   시트에 `교인명부 / 출석 / 헌금생활 / 기록 / _설정` 탭이 생깁니다. 여러 기기의 변경은 최신 수정 기준으로 합쳐집니다.
6. *헌금생활 → 구글시트에서 가져오기*는 기존 헌금집계 시트(설정의 시트 ID)에서 항목만 읽어옵니다.
   이 기능을 쓰려면 스크립트를 만든 계정이 헌금집계 시트를 볼 수 있어야 합니다.

### 태블릿에서 출석체크
태블릿(안드로이드·아이패드) 브라우저로 4번의 웹앱 URL을 열고 KEY를 한 번 입력하면, 같은 화면에서 탭으로 출석체크하고 구글시트에 바로 저장됩니다. 데스크탑은 *지금 동기화*로 받아옵니다.
> 웹앱 URL을 아는 사람은 누구나 화면을 열 수 있으므로, KEY는 교인 정보 담당자만 알도록 관리하세요.

## 4. GitHub 자동 업데이트
설치 파일은 GitHub가 대신 만들고(Actions), 설치된 프로그램은 켤 때마다 GitHub Releases를 확인해 새 버전을 자동으로 받아 설치합니다. 데이터(`문서\성현교회출석부`)는 업데이트해도 그대로입니다.

**준비 (한 번만)**: Git for Windows와 Node.js(LTS)가 설치된 PC
1. GitHub에서 새 저장소를 만듭니다 (예: `seonghyeon-roll`, **Public 권장**, README 추가하지 않음).
   - 저장소에는 프로그램 코드만 올라가고 교인 데이터는 올라가지 않습니다.
   - Private로 하면 설치된 프로그램이 업데이트를 받지 못합니다 (별도 토큰 필요).
2. 이 폴더에서 `1_GitHub_first_upload.bat` 실행 → 저장소 주소 입력.
3. GitHub의 **Actions** 탭에서 빌드가 끝나면(5~10분) **Releases**에 `SeonghyeonRoll-Setup-x.y.z.exe`가 생깁니다. 이 파일로 각 PC에 한 번 설치합니다.

**새 버전 낼 때**
1. 코드를 고친 뒤 `2_release_new_version.bat` 실행 → 바뀐 내용 한 줄 입력.
2. 버전이 자동으로 0.0.1 올라가고 GitHub에 올라갑니다. 5~10분 뒤 Releases에 새 설치 파일이 생깁니다.
3. 각 PC는 다음에 켤 때(또는 6시간마다) 새 버전을 받아 "지금 다시 시작 / 나중에" 를 묻습니다. *파일 → 업데이트 확인*으로 바로 확인할 수도 있습니다.

> `gas/Code.gs`의 `KEY`에는 실제 비밀번호를 넣지 마세요. 실제 비밀번호는 Apps Script 편집기에서만 바꿉니다.

## 5. 개발자용
```
npm install
npm start          # 실행
npm run dist       # Windows PC에서 설치 파일(.exe) 직접 만들기 (업로드 없음)
node build-gas.js  # renderer/index.html 수정 후 gas 폴더 갱신
```
